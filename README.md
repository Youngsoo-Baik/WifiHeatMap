# Wi-Fi Heatmap MVP

아파트 평면도 위에서 실제 Wi-Fi 신호 세기(RSSI)를 여러 지점에서 측정하고, 색상 히트맵과 음영 후보를 표시하는 Android MVP입니다.

## 포함 기능

- JPG/PNG 평면도 이미지 불러오기
- 첨부된 아파트 평면도를 앱 시작 기본값으로 표시
- 상단 `평면도 변경` 버튼으로 다른 이미지 선택
- 평면도에서 측정 위치 선택
- 현재 연결된 Wi-Fi의 RSSI(dBm) 기록
- 평면도에서 공유기와 증폭기 위치 지정
- 장비 하나에 여러 BSSID(2.4/5/6GHz 라디오) 연결
- 측정 위치에서 주변 AP를 스캔해 장비별 신호 구분
- 측정점 선택 시 AP·주파수·RSSI·BSSID 상세 표시
- 등록 장비별 히트맵 필터
- 평면도·장비·BSSID·측정점·AP별 RSSI를 앱 내부에 저장
- 저장 시각과 데이터 개수를 확인하고 측정 세션 복원
- 공유기·증폭기 위치와 기존 측정점으로 다음 측정 위치 추천
- 약한 신호 경계와 측정되지 않은 실내 영역 우선 탐색
- 여러 측정값을 역거리 가중 보간(IDW)한 히트맵
- 강함(초록) → 양호(노랑) → 약함(주황) → 음영(빨강) 색상 표시
- `-75 dBm` 이하 측정 지점을 음영 후보로 집계
- 마지막 측정 취소 및 전체 초기화

## 사용 방법

1. Android 휴대폰의 Wi-Fi를 측정할 공유기에 연결합니다.
2. 기본 평면도를 사용하거나 `평면도 변경`을 눌러 다른 이미지를 선택합니다.
3. `장비 추가`를 누르고 공유기 또는 증폭기가 설치된 위치를 탭합니다.
4. 장비 종류와 이름을 입력하고 해당 장비의 BSSID를 선택합니다.
5. 실제로 서 있는 위치를 평면도에서 탭합니다.
6. `이 위치에서 모든 Wi-Fi 신호 측정`을 누르고 권한을 허용합니다.
7. 집 안을 이동하며 3~5m 간격, 방마다 2~4곳을 반복 측정합니다.

측정점을 다시 탭하면 해당 위치에서 수신한 장비별 신호가 표시됩니다. 평면도 오른쪽 위의 `히트맵` 버튼을 누르면 전체 신호와 등록 장비별 히트맵을 전환할 수 있습니다.

측정을 마친 뒤 `결과 저장`을 누르면 현재 세션 하나가 앱 내부 저장소에 보관됩니다. 앱을 다시 실행한 뒤 `결과 불러오기`를 누르면 저장된 평면도, 장비와 측정값을 함께 복원합니다. 새로 저장하면 이전 세션을 덮어쓰며, 앱을 삭제하면 저장 데이터도 삭제됩니다.

`위치 추천`을 누르면 첫 측정은 공유기 근처 기준점으로 안내합니다. 이후에는 공유기·증폭기와 기존 측정점 사이의 거리, 예상 신호 강도, 평면도 이미지의 실내 후보 영역을 함께 평가해 다음 측정 위치를 보라색 마커로 표시합니다. 추천 위치가 실제로 이동할 수 없는 벽이나 실외라면 가까운 실내 지점을 직접 선택하세요.

정확도를 높이려면 각 위치에서 3~5초 머문 뒤 측정하고, 휴대폰 높이와 방향을 비슷하게 유지하세요.

## Android Studio에서 실행

1. Android Studio에서 이 폴더를 `Open`합니다.
2. Gradle Sync가 끝날 때까지 기다립니다.
3. `Device Manager`에서 API 23 이상의 에뮬레이터를 실행합니다.
4. 실행 구성에서 `app`을 선택하고 Run(▶)을 누릅니다.

프로젝트는 Android Studio Iguana(2023.2), Android Gradle Plugin 8.3.2, Gradle 8.4, JDK 17 조합과 호환됩니다. `Gradle JDK`는 Android Studio 내장 JDK를 사용하세요.

## 명령줄 빌드 및 설치

요구 환경은 JDK, Android SDK Platform 34, Build Tools 34.0.0입니다. Gradle이나 외부 라이브러리는 사용하지 않습니다.

Gradle 빌드:

```bash
./gradlew assembleDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

외부 의존성 없이 Android SDK 도구로만 빌드하는 기존 방식도 유지됩니다.

```bash
./build.sh
adb install -r build/out/wifi-heatmap-mvp.apk
```

## MVP 한계

- 벽, 문, 재질을 인식하지 않고 측정점 사이를 수학적으로 보간합니다.
- Android의 Wi-Fi 스캔 빈도 제한으로 빠르게 연속 측정하면 최근 스캔 결과를 사용할 수 있습니다.
- 측정 세션은 앱 메모리에만 유지되며 앱 종료 후 복원되지 않습니다.
- Android 기기 제조사와 OS 정책에 따라 Wi-Fi 또는 위치 서비스 활성화가 필요할 수 있습니다.
